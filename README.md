## What it does

`main.py` (Python 3.13, standard library only) writes a single deadpan
weather forecast for Vexford — a city that does not exist — to
`/output/entry.txt`. One line, 151 characters, deterministic and
byte-identical on every run:

> In Vexford, expect 19 degrees and a light rain of confetti, clearing by noon, with winds gusting to 47 and a 60% chance the mayor apologises by Friday.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
